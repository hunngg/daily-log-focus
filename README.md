# Daily Log

適用 GitHub Pages 的純靜態網頁工具。請將本資料夾**內的檔案**上傳至 GitHub 儲存庫根目錄（不是將整個資料夾作為一層子目錄）。

## 發布
1. 建立 Public repository，例如 `daily-log-focus`。不要填入任何真實人名或私人故事。
2. 使用 **Add file → Upload files**，上傳 `index.html`、`manifest.webmanifest`、`sw.js`、`icon.png`、`icon-512.png`、`.nojekyll`（隱藏檔案上傳不便可略過），提交變更。
3. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**。
4. 等待 GitHub 顯示網站網址，通常是 `https://使用者名稱.github.io/儲存庫名稱/`。
5. 用 iPhone Safari 開啟網站 → 分享 → 加入主畫面。

## 隱私與限制
- GitHub Pages 網站及公開儲存庫內容可被任何人存取，請勿將私人訊息或個人資訊寫進原始碼或儲存庫。
- 練習次數儲存在裝置的 localStorage，**未加密**；清除網站資料或更換裝置可能遺失。
- 暫存文字不會上傳或寫入 localStorage；但在頁面開啟期間，能看到螢幕的人仍可能讀取。
- 網站不具備密碼鎖、Face ID 驗證或阻止 LINE 訊息發送的功能。
- 不會發送通知。緩衝計時不是背景鬧鐘，離開網頁不會通知時間到。
- 完成按鈕需等待 10 分鐘倒數結束才能計入完成紀錄。

## 此版本修正與驗證
- 保留原版介面及五種情境；草稿只在記憶體中，返回、開始緩衝、切換至背景或離開頁面時清除。
- 本機只儲存完成日期／情境代碼及進行中的截止時間／情境代碼；不儲存草稿、感受強度或個人識別資訊。
- 10 分鐘倒數以時間戳記計算，重新載入或鎖屏後返回可恢復；返回首頁或先離開會取消這次計時。到時需手動按完成才計入統計。
- 最近 14 天依裝置當地日期計算；「累積練習」為所有歷史完成次數。
- Manifest 的 id、scope、start_url、圖示及 Service Worker 均使用相對路徑，可部署於 `/daily-log-focus/`。首次線上載入並完成快取後才可離線使用。
- Service Worker 僅快取本工具靜態檔案，採網路優先、離線回退，更新版本時清理舊快取。
- 無外部字型、分析、第三方套件、訊息傳送或記錄上傳功能。GitHub 仍可能保留一般靜態網站存取紀錄（例如 IP）；私人草稿不會包含在請求中。
- 日期與倒數依裝置時鐘；更改時鐘會影響計時。Safari 與加入主畫面的 App 可能使用各自的本機資料，請固定使用同一入口。

## 驗證方式
以 390 × 844 觸控視窗自動操作五種情境、草稿清除、倒數完成限制、重新載入恢復、延長倒數及統計；另檢查發布後頁面、相對資源路徑與離線快取。
